# HUNT: Hard RP — Universal Item Icon Style Guide (SVG)

## 1. Концепция и философия дизайна
Все иконки предметов инвентаря выполняются в **чистом, строгом векторном стиле (SVG)** с аутентичной атмосферой выживания и дикого запада (DayZ / Red Dead Redemption 2).
- **Минимализм и четкость:** векторные линии без лишнего визуального шума, идеальная читаемость на темном фоне сетки.
- **Чистые блики и акценты:** аккуратные световые скосы и блики, придающие предметам объем.
- **Единые стандарты:** одинаковая толщина штриха (`stroke-width`), скругления (`round`), скоординированные пропорции.

---

## 2. Размеры и пропорции (ViewBox)
Сетка инвентаря состоит из ячеек `44x44px` с шагом `1px`. Каждый предмет использует `viewBox`, строго соответствующий его форме в сетке:

| Размер | Пропорции | ViewBox | Категории предметов |
|---|---|---|---|
| **1x1** | Квадрат | `viewBox="0 0 28 28"` | Патроны, спички, консервы, бинты, часы, монеты, компас |
| **1x2** | Вертикальный | `viewBox="0 0 28 44"` | Бутылки, ножи, фляги, топорики, фонари, шприцы |
| **2x1** | Горизонтальный | `viewBox="0 0 44 28"` | Пистолеты, револьверы, слитки, свёртки, коробки патронов |
| **1x3** | Длинный верт. | `viewBox="0 0 28 64"` | Мачете, факел, лопата, удочка |
| **3x1 / 4x1** | Длинный гориз. | `viewBox="0 0 64 28"` / `0 0 88 28` | Карабины, винтовки, дробовики, лук |
| **2x2 / 2x3** | Крупный | `viewBox="0 0 44 44"` / `0 0 44 64` | Рюкзаки, куртки, шкуры, капканы, ящики |

## 3. Цветовая палитра и параметры линий

| Элемент | Цвет (Hex) | Stroke-Width | Описание / Правила |
|---|---|---|---|
| **Главный контур (Silhouettes)** | `#e2e8f0` | `1.8` | Основные границы предмета (`stroke-linecap="round" stroke-linejoin="round"`). |
| **Вторичные детали (Accents)** | `#94a3b8` / `#cbd5e1` | `1.2` – `1.4` | Кольца, застежки, спусковые крючки, швы, винты, ремни. |
| **Световые блики (Highlights)** | `#ffffff` | `1.2` – `1.4` | Полупрозрачные линии скоса (`opacity="0.35"` – `0.55"`). |
| **Дерево (Wood)** | `#b45309` / `#78350f` | fill / stroke | Рукояти револьверов, приклады, топорища (`stroke-width="1.4"`). |
| **Кожа / Ткань (Leather / Cloth)** | `#92400e` / `#64748b` | fill / stroke | Рюкзаки, шляпы, ножны, бинты, мешки. |

| **Медицина (Medical)** | `#ef4444` / `#10b981` | fill / stroke | Крест на аптечке, антисептик, чистые бинты. |

## 4. Стандарты по категориям предметов

### А. Огнестрельное оружие (Guns)
- Расположение горизонтальное (`2x1`, `3x1`, `4x1`).
- Ствол, барабан/затвор — серебристый контур `#e2e8f0`.
- Приклад/рукоять — дерево `#b45309` или темный полимер `#475569`.
- Световой блик вдоль верхней грани ствола (`#ffffff` opacity `0.45`).

### Б. Холодное оружие и инструменты (Melee & Tools)
- Лезвие: четкая режущая кромка со скосом `#ffffff` (opacity `0.5`).
- Обух и гарда: `#94a3b8` (opacity `0.9`).
- Рукоять с насечками или обмоткой.

### В. Патроны и боеприпасы (Ammo)
- Гильза: латунь/золото `#f59e0b` (fill или stroke).
- Пуля/наконечник: свинец/медь `#e2e8f0` или `#ea580c`.
- Для коробок патронов: коробка с маркировкой калибра.

### Г. Еда, провизия, мясо и травы (Food & Plants)
- Мясо / Рагу: характерный силуэт стейка/окорока с белой косточкой (`#ffffff`) и текстурными волокнами.
- Консервы: цилиндрическая банка с ключом/кольцом для открывания.
- Растения/Травы: стебель и резные листья с тонкими прожилками (`stroke-width="1.2"`).

### Д. Медицина и восстановители (Medicine)
- Бинты: рулон с видимыми слоями ткани и полоской фиксатора.
- Тоники / Настойки: стеклянная склянка с янтарным (`#f59e0b`) или изумрудным (`#10b981`) эликсиром.

### Е. Ресурсы и крафт (Crafting Materials)
- Доски / Бревна: древесная текстура с годовыми кольцами на срезе.
- Металл / Слитки: трапециевидная форма со световыми гранями.
- Веревка / Ткань: витая спиральная структура.

## 6. Местоположение в проекте
- Все SVG-иконки регистрируются в объекте `SVG_ICONS` внутри `thehunt_inventory/html/app.js`.
- Названия ключей в `SVG_ICONS` должны совпадать с полем `name` или `icon` из реестра `thehunt_items/shared/items.lua`.
