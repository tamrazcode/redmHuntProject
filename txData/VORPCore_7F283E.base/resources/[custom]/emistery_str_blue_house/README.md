# Strawbery Blue House | Emistery

-------------------------------------------------------
# How to install ?

Copy emistery_str_blue_house depository into the resources folder. 

Then in the server.cfg or resources.cfg
add the line

ensure emistery_str_blue_house


Restart Server.

- WARNING : If you have more than 1 MLO in the area, you might encounter compatibility issues. Please open a ticket on discord if that's the case, we will provide a fix.
----------------------------------------------------------------------------------------------------
# Custom Props

If you want to use the custom props included in this MLO, you can spawn them using any proloader like spooner and spawn by name :

rug_2
rug_19

 - WARNING : emistery_str_blue_house needs to be active on your server for the props to work properly.
