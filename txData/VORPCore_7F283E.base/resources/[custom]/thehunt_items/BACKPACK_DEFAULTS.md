# Стандартная посадка рюкзаков

Администратор надевает нужную модель, закрывает инвентарь и вводит `/bpdefault`.
Перемещение и вращение в этом режиме не ограничены. «Сохранить» записывает
профиль этой модели в `thehunt_items/backpack_defaults.json` на сервере.
Файл автоматически читается после перезапуска; сохраняйте его при обновлении ресурса.
Права проверяются через `thehunt_core:IsPlayerAdmin`, включая повторную проверку при сохранении.

Профиль общий для всех экземпляров модели и реплицируется всем клиентам.
Во время калибровки личное смещение исключается; при сохранении оно сбрасывается
только у калибруемого предмета, чтобы посадка после выхода точно соответствовала
редактору. Отмена сохраняет прежнее личное смещение. Чтобы увидеть чистый стандарт у другого ранее настроенного
предмета, откройте обычное «Расположение», нажмите «Сбросить» и «Сохранить».
Отмена администраторской настройки не меняет сохранённый стандарт.

Обычная настройка сохраняется отдельно в metadata предмета. Её пределы:
±35 см по каждой оси и ±180° вращения. Gizmo использует прежнее управление.

После установки кода требуется загрузить обновлённые `thehunt_items` и
`thehunt_inventory` (предпочтительно при плановом перезапуске сервера).
В игре проверить надевание, сохранение стандарта каждой модели, личное смещение,
отмену, повторный вход и отображение на втором клиенте.
