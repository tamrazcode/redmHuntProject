# HUNT: Hard RP — The Character System (`thehunt_character`)

Полноценная, высокопроизводительная и модульная система создания, сохранения, управления и выбора персонажей для **RedM** на базе **VORP Framework**.

Разработана специально для сеттинга постапокалипсиса и хард-РП сервера **HUNT**, полностью заменяет устаревший `vorp_character` и обеспечивает 100% обратную совместимость со всеми ресурсами проекта (инвентарь, дома, двери, статус-HUD, крафт, оружие).

---

## 🌟 Ключевые возможности

1. **Уникальный 5-значный код персонажа (`00001`–`99999`)**:
   - Гарантированная уникальность на уровне базы данных (таблица `thehunt_character_codes`).
   - **Историческое резервирование**: код никогда не перевыдается новому персонажу даже после полного удаления старого.
   - Экспортный API для других ресурсов (`exports['thehunt_character']:GetCharacterCode(source)`).
   - Интеграция в админ-панель `thehunt_core` с возможностью поиска игроков по коду.

2. **Современный NUI-интерфейс (Обсидиановый стиль HUNT)**:
   - Глубокий обсидиановый фон (`#0c0c0f` — `#15151a`), чистый белый и приглушённый стальной текст (`#ffffff`, `#8c909c`), тонкие рамки и шрифт `Inter` / `Segoe UI` / `Roboto`.
   - Векторные SVG-иконки без эмодзи.
   - Полное соответствие стандарту блокировки ввода `ui_controls_guidelines.md` (полная блокировка клавиш при фокусе в полях ввода текста).

3. **Character Selection (Выбор персонажа)**:
   - Атмосферные 3D-локации (Ван Хорн, Салун Армадилло, Которра Спрингс) с погодными эффектами и кинематографичной камерой.
   - Живой предпросмотр персонажа с анимациями лобби (`MP_LOBBY_SCENARIO`).
   - Карточки слотов с отображением 5-значного кода, профессии, баланса и возраста.
   - Безопасное удаление персонажа с подтверждением через ввод точного имени (`John Smith`).

4. **Character Creator (Создание персонажа)**:
   - Мгновенный Realtime-предпросмотр всех изменений внешности без задержек.
   - Наследие и базовые формы лиц (Heads).
   - Детальные ползунки черт лица (глаза, брови, нос, скулы, челюсть, подбородок, губы, рот, шея, плечи, торс, ноги).
   - Прически, бороды и усы с палитрами цветов.
   - Оверлеи и косметика (шрамы, веснушки, родинки, старение, дефекты, грязь, тени, помада, подводка, боевая раскраска).
   - Стартовый гардероб одежды с разделением по категориям и разрешением конфликтов.
   - Панель управления камерой (пресеты: Лицо, Торс, Голова, Обувь, Полный рост; свободное вращение на СКМ, зум колесиком).

5. **Гибкая система слотов**:
   - Обычные игроки: по умолчанию **3 слота** (настраивается в `config.lua`).
   - Администраторы: **неограниченное** количество слотов.

6. **Безопасная миграция существующих персонажей VORP**:
   - Сохранение всех существующих персонажей без потери внешности, одежды, инвентаря и денег.
   - Поддержка Dry-Run режима (`hunt_migrate dry`) и выполнения (`hunt_migrate run`).

## 🚀 Установка и настройка

### Шаг 1: База данных
Выполните скрипт `sql/schema.sql` в вашей базе данных (через HeidiSQL, DBeaver или phpMyAdmin).

### Шаг 2: server.cfg
В файле `server.cfg`:
1. Закомментируйте старый `vorp_character`:
   ```cfg
   # ensure vorp_character
   ```
2. Добавьте `thehunt_character` в секцию кастомных скриптов:
   ```cfg
   ensure thehunt_character
   ```

### Шаг 3: Миграция существующих персонажей VORP
1. В консоли сервера выполните проверку (Dry Run):
   ```text
   hunt_migrate dry
   ```
   Консоль выведет статистику существующих персонажей и количество тех, кому будет выдан 5-значный код.
2. Примените миграцию:
   ```text
   hunt_migrate run
   ```
   Каждому существующему персонажу будет присвоен постоянный уникальный 5-значный код, сохранив все данные VORP.

## 🔌 API и Экспорты

### Серверные экспорты (Lua)

#### Получить 5-значный код персонажа по server ID (source)
```lua
local code = exports['thehunt_character']:GetCharacterCode(source)
-- Возвращает: "04827" (строка ровно из 5 цифр) или nil
```

#### Получить 5-значный код по charIdentifier базы данных
```lua
local code = exports['thehunt_character']:GetCharacterCodeById(charIdentifier)
-- Возвращает: "04827" или nil
```

#### Найти данные персонажа по его 5-значному коду
```lua
local character = exports['thehunt_character']:GetCharacterByCode("04827")
-- Возвращает строку из таблицы characters или nil
```

## 🎮 Команды

- `/rc` — мгновенно перезагрузить внешний вид персонажа, очистить кровь/грязь и восстановить одежду (доступна игрокам).
- `/hunt_migrate dry` — проверить состояние миграции персонажей VORP (только для консоли / администраторов).
- `/hunt_migrate run` — выполнить миграцию персонажей VORP и выдать коды (только для консоли / администраторов).
