# Эксперимент: бледный «зомби»-композит MetaPed

## Что это за эффект

Бледная серо-белая кожа, которую раньше давал экран создания, была не
отдельным готовым оверлеем, а результатом неверной конфигурации композитора:
обычный слой кожи создавался как цветной (`tx_color_type = 0`) с пустой
палитрой. MetaPed при этом тонирует весь композит головы, а не только шрам.

В обычном создании персонажа этот режим запрещён: шрамы, старение, веснушки,
родинки и пятна применяются как неокрашиваемые слои (`tx_color_type = 1`).

## Как воспроизвести только для тестового NPC-зомби

Не добавлять это в пользовательский creator. На отдельном локальном или
сетевом педе, после применения базовой головы и тела, временно передать в
`Appearance.ApplyOverlays` тестовый слой с такими параметрами:

```lua
skin.overlays.ageing = {
    visibility = 1,
    tx_id = 1,
    tx_normal = 0,
    tx_material = 0,
    tx_color_type = 0, -- намеренно: режим окрашиваемого слоя
    tx_opacity = 1.0,
    tx_unk = 0,
    palette = 0,       -- намеренно пустая палитра даёт бледный композит
    palette_color_primary = 0,
    palette_color_secondary = 0,
    palette_color_tertiary = 0,
    var = 0,
    opacity = 0.85
}
```

Затем добавить шрамы и старение обычными слоями поверх него. Это лишь
визуальный прототип: поведение зависит от конкретной головы, освещения и
версии RedM. Для постоянных зомби лучше сохранить отдельный пресет внешности
NPC, а не смешивать такой режим с данными игрока.
