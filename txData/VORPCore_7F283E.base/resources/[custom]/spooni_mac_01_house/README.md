# 🏠 spooni_mac_01_house

## 1. Installation
spooni_mac_01_house works Standalone.  

To install spooni_mac_01_house:
- Drag and drop the resource into your resources folder
  - `spooni_mac_01_house`
- Add this ensure in your server.cfg
  - `ensure spooni_mac_01_house`
- At the end
  - Restart the server


---------------------------------------------------------
----> Update <----
If you have any Mappings from the Update Folder
copy the File from the "Update" Folder 
to the "stream" Folder from "the Mapping" and 
to the stream Folder from "spooni_mac_01_house" and replace it.

Restart Server 
finish.
