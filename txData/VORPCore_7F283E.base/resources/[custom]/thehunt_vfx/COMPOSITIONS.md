# Композиции VFX

Существующие эффекты, сцены и одиночные пресеты сохранены. Композиция — до 24 слоёв с индивидуальными параметрами и временем старта, общей длительностью до 600 секунд. Локальный тест Studio ограничен 30 секундами.

## Работа в Studio

1. Выберите эффект в каталоге, настройте его справа.
2. На вкладке «Композиция» добавьте слой. Для каждого слоя задайте время старта. Полоса показывает интервал его жизни.
3. «Редактировать справа» загружает параметры. «Заменить параметрами справа» применяет изменения к слою.
4. В разделе «Движение и плавные переходы» включите анимацию: прямая (метры/сек), орбита XY (радиус и градусы/сек), вращение по трём осям, появление, затухание, конечный масштаб.
5. Выберите общую точку в мире либо игрока. Привязка и кость сохраняются отдельно для каждого слоя. Генератор пары на ступнях создаёт два привязанных слоя.
6. Тестируйте, сохраняйте под именем справа, запускайте для игроков. Сохранённые композиции доступны во вкладке пресетов. «Остановить мои композиции» отменяет также ещё не запущенные слои.

Экспорт JSON не содержит привязки к конкретному игроку или мировых координат. Для импорта нажмите «Экспорт JSON», замените текст в поле своим JSON и нажмите «Импорт JSON из поля». Окончательная проверка выполняется при тесте/сохранении.

## API

```lua
local id, err = exports['thehunt_vfx']:PlayPreset('Имя композиции', {
    coords = { x = 100.0, y = 200.0, z = 30.0 },
    targetServerId = playerId -- server; нужен для слоёв на игроке
}, { bucket = 0 }) -- options только на сервере
-- Вызвать из того же ресурса:
exports['thehunt_vfx']:StopSequence(id)
```

На клиенте контекст может содержать `entity = PlayerPedId()`. Одиночные пресеты по-прежнему останавливаются `StopEffect`. Композиции — `StopSequence`.

`PlaySequence({ duration=10, phases={...} }, context, options)` принимает слои `{ at=0, effectId='...', params={...} }`.

Параметры анимации слоя:

```lua
animation = {
    mode = 'orbit', radius = 2.0, speed = 90.0,
    velocity = {x=0.0,y=0.0,z=0.0},
    spin = {x=0.0,y=0.0,z=30.0},
    fadeIn = 0.5, fadeOut = 1.0, endScale = 2.0
}
```

Орбита и прямая изменяют положение эмиттера. Уже выпущенные частицы следуют собственной физике эффекта. Разовые эффекты нельзя отозвать после выпуска; остановка предотвращает следующие выпуски. Для следов выбирайте соответствующий PTFX и привязывайте к движущейся кости. Цвет, масштаб и альфа поддерживаются самими эффектами неодинаково.

## Границы поддержки

AnimPostFX доступны локально. Timecycle по умолчанию отключён из-за общего канала с погодой и состоянием персонажа. Эти средства не являются загрузчиком произвольных шейдеров. Собственных моделей, текстур порталов или шейдерных ассетов этот пакет не содержит. Название в каталоге femga не означает подтверждённую видимость на сервере.

Анимационные native-вызовы сверены с https://github.com/alloc8or/rdr3-nativedb-data . Функциональность проверяется изолированными тестами, без запуска RedM/FXServer. Плавность, визуальный результат, поведение движения world-space PTFX и FPS требуют проверки в игре.

## Короткая игровая проверка владельцем

После ручного обновления ресурса: один цикл при alpha=1; затем орбита с fadeIn/fadeOut; два слоя со стартом 0 и 2 секунды; отмена до второго слоя; сохранение и загрузка композиции; запуск для второго игрока того же bucket; отсутствие эффекта в другом bucket. После окончания не должно оставаться света или циклических частиц. Игру и сервер автоматические тесты не запускают.
