# HUNT VFX Studio 4

## Таймлайн, группы, сцены и диагностика

- Перетаскивайте голубую полосу слоя для изменения начала; правый край меняет длительность. Шаг — 0.05 секунды. Числовое поле остаётся доступно.
- Предпросмотр: с начала, с курсора, только редактируемый слой, пауза, продолжение, повтор, скорость 0.25–2×. Сеанс ограничен 30 секундами; можно просматривать участок длинной композиции. Пауза прекращает эмиссию; продолжение/перемотка пересоздают частицы. Скорость относится к таймлайну и анимации, а не внутренней симуляции частиц RedM.
- Группы: отметьте слои, назначьте имя; применяйте общий перенос, вращение и масштаб. Изменения записываются в параметры/кадры, отменяются историей. Генератор создаёт кольцо, сферу, спираль или волну с количеством, радиусом, высотой, витками и задержкой. Общий лимит — 24 слоя.
- Ключевые кадры редактируются списком в инспекторе: добавить, выбрать, обновить, удалить, изменить время. Затем примените параметры к слою. JSON остаётся расширенным способом обмена.
- Общие теги и заметки доступны для поиска. Недавние эффекты хранятся локально. Сборкам можно дать описание и вручную отметить проверку в игре; есть фильтр проверенных сборок. Наличие отметки зависит от проверки администратора, не от успешного вызова native.
- В «Мир и сцены» доступны поиск, скрытие/показ, скрытая копия, перенос в точку инспектора, удаление и восстановление одной из последних 8 версий. Изменения сохраняются сервером, с проверкой прав и измерения; неудачная запись не применяется. Редактирование сохраняет предыдущую версию. История удаляется вместе со сценой.
- «Диагностика» показывает локально загружаемые/активные эффекты, ошибки, источники света и остановку своих тестов. Это не измеритель количества отдельных частиц внутри движка.

Дополнительные проверки: `tests/advanced.py` (серверное сохранение и транспорт с имитацией natives), `tests/advanced_browser.py` (интерфейс Edge с имитацией NUI). Живой RedM не запускается этими тестами.

## Обновление рабочего процесса студии

Встроенная инструкция раскрывается под названием проекта. Инспектор объясняет
особенности выбранного типа эффекта. Редактируемый слой выделяется голубым;
«Применить к слою» сохраняет его включённое/выключенное состояние.
Слои можно переставлять стрелками, дублировать (до 24), очищать и возвращать историей.
Диагностика блокирует запуск пустой композиции, всех выключенных слоёв и слоёв,
начинающихся за пределами длительности. Импорт ограничен теми же 24 слоями.

Черновик композиции и название автоматически сохраняются в локальном хранилище
NUI. При следующем открытии доступна кнопка восстановления; это не серверный пресет
и не постоянная сцена. Для переноса используйте JSON или сохраните пресет.
Ctrl+F открывает поиск, Ctrl+Enter тестирует текущий эффект/композицию,
Ctrl+Z и Ctrl+Shift+Z управляют историей композиции вне полей ввода.
Кнопка копирования Lua при недоступности буфера выделяет текст для Ctrl+C.

Проверки `tests/workflow.py` покрывают восстановление черновика, историю,
выключенные слои, лимиты, время запуска, совместимость одиночной кости
и отсутствие горизонтального переполнения при 1366×768 и 1920×1080.
Это браузерные проверки с имитацией NUI, а не подтверждение визуальных эффектов в RedM.

Полностью новая реализация. Другие ресурсы сервера не изменены.
Открыть: /vfx или F6. Права проверяет сервер через thehunt_core:IsPlayerAdmin.

## Студия

1. Найдите эффект по имени/словарю и типу. Каталог постраничный.
2. Выберите точку (свои координаты, указатель поверхности, числовые XYZ)
   или привязку к себе/игроку и кости. Задайте смещение, поворот, масштаб, цвет.
3. «Тест локально» запускает один предпросмотр до 30 секунд. Новый тест заменяет старый.
   Закрытие окна останавливает предпросмотр, включая незавершённую загрузку.
4. «Виден» / «Не виден» — ручная проверка именно на этом сервере.
   Она хранит имя проверявшего, дату и game build, но не делает эффект универсально рабочим.
5. «Запустить для игроков» создаёт серверный эффект в вашем routing bucket.
   Время 0 для циклов/света означает до явной остановки.
6. «Мир и сцены» → «Параметры» → «Применить» редактирует существующий эффект.
   «Сохранить сцену» сохраняет фиксированную точку с циклом или светом.
   «Удалить» удаляет выбранный эффект, включая сохранённую сцену.
   Массовая остановка затрагивает только временные эффекты данного bucket.
7. Пресет сохраняет параметры без координат и цели. Вкладка API формирует Lua-вызов.

Во время ввода блокируется всё игровое управление; иначе доступна ходьба/голос.
СКМ — осмотр; указание точки — ЛКМ, отмена ПКМ/Esc.
NUI использует Obsidian и прозрачность без CSS blur.

## Каталог и границы проверки

Скачано с upstream femga/rdr3_discoveries:
- 1175 уникальных dictionary/name пар циклических PTFX;
- 1141 пар разовых PTFX;
- 533 AnimPostFX;
- 991 timecycle;
- отдельный программный точечный свет light|point.

Источники:
- https://github.com/femga/rdr3_discoveries/blob/master/graphics/ptfx/ptfx_assets_looped.lua
- https://github.com/femga/rdr3_discoveries/blob/master/graphics/ptfx/ptfx_assets_non_looped.lua
- https://github.com/femga/rdr3_discoveries/blob/master/graphics/animpostfx/animpostfx.lua
- https://github.com/femga/rdr3_discoveries/blob/master/graphics/timecycles/timecycles.lua
- Сигнатуры RedM: https://github.com/alloc8or/rdr3-nativedb-data
- Серверные границы: https://docs.fivem.net/docs/developers/server-security/

Это полные индексы имён, а НЕ список визуально проверенных эффектов.
Словарь запрашивается/проверяется по HASH, выбирается перед эмиссией по STRING.
Успешный native handle означает успешный запуск, но не гарантирует видимость:
сюжетные эффекты могут требовать особого объекта/материала/контекста.
Поддержка перекраски также зависит от конкретного эффекта.
Разовые частицы после эмиссии не имеют управляемого loop handle и исчезают сами;
остановка отменяет только ещё не выполненные повторы.

AnimPostFX доступны локально до 30 секунд, при совпадении с уже запущенным
экранным эффектом запуск отклоняется. Глобальный AnimpostfxStopAll не вызывается.
Timecycle видны в каталоге, но Config.AllowTimecycle=false: канал общий с другими
ресурсами. Включение осознанно допускает замену текущего модификатора; снятие
своего модификатора не восстанавливает неизвестное состояние чужого ресурса.
Сетевые экранные эффекты и повреждающие взрывы не поддерживаются.

## API (client и server)

Локальный клиентский эффект:
```lua
local id, err = exports.thehunt_vfx:PlayEffect(
    'ptfx_looped|core|ent_amb_elec_crackle',
    { entity = PlayerPedId(), attach = true, bone = 'SKEL_R_Hand',
      scale = 0.4, lifetime = 3 }
)
-- Только вызвавший ресурс может остановить свой эффект:
if id then exports.thehunt_vfx:StopEffect(id) else print(err) end
```

Серверный запуск виден клиентам выбранного bucket. Урон и возможность
применения магии проверяются В ВЫЗЫВАЮЩЕМ серверном ресурсе.
```lua
local id, err = exports.thehunt_vfx:PlayEffect(
    'ptfx_looped|core|ent_amb_elec_crackle',
    { targetServerId = source, attach = true, bone = 'SKEL_R_Hand',
      scale = 0.4, lifetime = 3 },
    { bucket = GetPlayerRoutingBucket(source) }
)
-- onlyTarget=true в options ограничивает показ одним targetServerId.
-- Для эффекта на земле используйте coords={x=...,y=...,z=...}, attach=false.
```

Последовательность (обе стороны). at — абсолютное время от начала, секунды.
delay принимается как псевдоним at. Все фазы отменяются вместе с sequence ID.
```lua
local sequence, err = exports.thehunt_vfx:PlaySequence({
    duration = 4,
    phases = {
        { at = 0, effectId = 'light|point',
          params = { color = {r=70,g=160,b=255}, lifetime=1.5 } },
        { at = 1.5, effectId = 'ptfx_non_looped|scr_lom_train|scr_ind1_firework_burst',
          params = { scale=0.5, repeatCount=1 } }
    }
}, { coords={x=0,y=0,z=80} }, { bucket=0 }) -- третье поле только server
-- Для прекращения:
exports.thehunt_vfx:StopSequence(sequence)
```

Фазы являются визуальными: перемещение снаряда/попадание/урон организует магия.
Сервер выдаёт sequence ID сразу; ошибка поздней фазы вызывает локальное
серверное событие thehunt_vfx:sequenceError(sequenceId, message, ownerResource).
Клиент выдаёт ID загрузки сразу, результат приходит локальным событием
thehunt_vfx:result(id, success, message). Ошибка загрузки не считается успехом.
GetActiveEffects() на клиенте возвращает состояния loading/playing/failed
только вызывающего ресурса.

Прочие exports:
- client/server: GetCatalog(), GetEffectInfo(id) (GetEffectInfo только client),
  PlayPreset(name, context [, options]), StopEffect(id).
- client: PlayMagic(def,context) — алиас PlaySequence; StopAllEffects() —
  только эффекты вызвавшего ресурса; GetActiveEffects().
- server: CreateNetworkedEffect({effectId=...,params=...}, options) —
  алиас PlayEffect; StopNetworkedEffect(id), GetPreset(name),
  GetPersistentScenes() — копия сохранённых сцен.
- Client PlayPreset требует первоначальную синхронизацию (примерно секунда после старта).

Параметры:
coords, entity (client), targetServerId, attach, bone, offset, rotation,
scale (0.01–10), alpha (0–1), color (RGB 0–255), lifetime (0–600 секунд),
range (0.1–40), intensity (0–30), repeatCount (1–12), repeatInterval (150–60000 мс).
Свет и разовые PTFX берут смещение кости в мировых осях; циклическая привязка
использует нативное локальное смещение кости.

## Сохранение и жизненный цикл

data/studio.json: version 4, scenes, presets, reviews. Успешной считается только
успешная запись SaveResourceFile; память меняется после неё.
Перед перезаписью сохраняется studio.json.bak. Повреждённый основной файл
блокирует дальнейшие записи до ручного восстановления.
Сцены принадлежат серверу и остаются после отключения автора.
Временные админские эффекты удаляются при отключении админа;
эффекты на игроке — при его отключении/смене bucket.
Эффекты API и незавершённые последовательности очищаются при остановке
вызвавшего ресурса. Поздние игроки получают текущие циклы, но не старые вспышки.
Удалённые эффекты стримятся по расстоянию; смена bucket убирает прежние эффекты.

## Проверено

tests/regression.py: Lua 5.4 parse + изолированные проверки прав, bucket,
таймеров, отмены загрузки/последовательности, owner cleanup и отказа записи.
tests/browser_smoke.py: Edge/Chromium, поиск/страницы каталога, NUI запросы,
координаты, генерация API, безопасный вывод названий и Esc.

Эти тесты используют mock natives и НЕ заменяют RedM/gameplay проверку.
Ресурс не перезапускался автоматически.

После restart thehunt_vfx:
- /vfx: свет и электричество, тест на себе/ладони/земле, остановка во время загрузки;
- два клиента в одном bucket: эффект виден обоим; в разных — изолирован;
- сохраните свет в сцену, переподключитесь и перезапустите ресурс;
- проверьте возврат управления при Esc и отсутствие вмешательства в персонажа/нокаут;
- отметьте реально видимые эффекты. Полный список автоматически рабочим не объявляется.
